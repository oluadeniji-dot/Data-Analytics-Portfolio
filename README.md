# Data Analytics Portfolio

A collection of data analytics projects showcasing SQL, Python, Excel, data cleaning, and interactive dashboards.

## Featured Project: Healthcare Data Analysis

Analyzed 20,190 records from the RAND Health Insurance Experiment public dataset.

### Skills Demonstrated
- SQL querying and data validation
- Python data analysis
- Excel reporting and visualization
- Interactive dashboard development
- Data cleaning and quality checks

### Project Files
- `index.html` — Interactive portfolio dashboard
- `Case_Study.pdf` — Project report
- `Analytics_Summary.xlsx` — Excel analysis

This portfolio demonstrates practical approaches to analyzing data and communicating insights.
